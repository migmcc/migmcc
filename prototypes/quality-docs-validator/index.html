Find gaps between PFMEA and Control Plan before they become surprises.

Quality Docs Validator cross-checks two XLSX workbooks using explicit rules and generates severity-classified potential findings. Runs locally, with no AI dependency.

View source on GitHub ↗Explore the checks

Why it exists

A PFMEA and a Control Plan may look complete when reviewed separately while missing a shared process step, special-characteristic control or reaction plan. This tool highlights potential inconsistencies for an engineer to assess.

What it does

Compare

Match process steps between PFMEA and Control Plan XLSX files.

Flag

Apply six documented checks and classify potential findings.

Report

Generate Markdown or JSON output for human review and automation.

Try it locally

pip install -e .
qdv pfmea-control-plan \
  --pfmea examples/pfmea.xlsx \
  --control-plan examples/control-plan.xlsx \
  --out report.md

Run from a local checkout of the repository with its bundled synthetic examples. Python 3.12+ required.

Scope and limitations

This tool supports, but does not replace, technical engineering review. Its findings are potential inconsistencies, not a certification of regulatory or standards compliance. It does not provide a web interface or QMS integration.
