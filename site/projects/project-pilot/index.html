ProjectPilot

Track project phases, required artefacts and human approval gates without allowing the tool to execute agents.

Source and README ↗Technical reference ↗
PythonLifecycleLocal-first
Why it matters

The problem

It is easy to lose track of a project's current phase, outstanding evidence and human approvals across different coding assistants.

How it works

The approach

A local deterministic process conductor records lifecycle state, checks phase requirements, recommends next actions and prepares prompts.

What it includes

  • Explicit idea-to-done lifecycle
  • Phase requirements and evidence inventory
  • Deterministic next-step advisor
  • Readable local dashboard and JSON output

Who it's for

Developers and solo builders using AI-assisted workflows

Evidence / example

An example tracks a planning phase from missing PRD to recorded evidence and the next required artefact.
