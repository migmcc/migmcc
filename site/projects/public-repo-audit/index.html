Public Repo Audit

Review documentation, licensing, packaging, tests, CI and basic safety hygiene before releasing a repository.

PythonGitHubCLI
Why it matters

The problem

A repository may be functional but still miss documentation, CI, licensing or other public-readiness signals.

How it works

The approach

A deterministic, local-only audit checks repository evidence and reports a score, blockers, warnings and recommendations.

What it includes

  • README, license and packaging checks
  • CI and tests readiness checks
  • Deterministic score and verdict
  • Markdown and JSON reports

Who it's for

Open-source maintainers and Python developers

Evidence / example

Documented example: score 100/100 and showcase-ready; actual results depend on the scanned repository.
