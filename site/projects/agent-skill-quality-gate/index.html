Agent Skill Quality Gate

Run deterministic checks on SKILL.md files for structure, clarity, duplication and basic safety heuristics.

Source and README ↗Technical reference ↗
AI AgentsSKILL.mdCI
Why it matters

The problem

As a library of AI agent skills grows, incomplete specifications and duplicated or suspicious instructions become harder to review consistently.

How it works

The approach

A Python standard-library CLI scans SKILL.md directories, applies its documented rules and emits scores and CI-friendly findings.

What it includes

  • Structural and clarity rules
  • Basic shell-risk heuristics
  • Duplicate-scope signals
  • Markdown and JSON output

Who it's for

Agent builders and teams maintaining skills

Evidence / example

The README includes a sample scan and an explicit breakdown of gate scores and severities.
