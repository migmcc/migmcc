Agent Desk

Coordinate model-specific prompts, dependencies, handovers and file-conflict checks for local AI-assisted development.

Source and README ↗Technical reference ↗
CodexClaude CodeWorkflow
Why it matters

The problem

Multi-agent work becomes difficult to audit when responsibilities, prompts, task dependencies and handovers are spread across tools.

How it works

The approach

A local-first CLI creates a structured task plan, prepares model-specific prompts, guards file scope and applies a deterministic quality gate.

What it includes

  • Routed task plan and manual model selection
  • Per-model copy-paste prompts
  • File reservations and dependencies
  • Structured handovers and quality gate

Who it's for

Developers working with Codex, Claude Code and local models

The README documents an end-to-end manual flow from new project to handover and gate.

Scope and trust

Important limitations

Agent Desk does not execute AI models, automatically push branches or create remote pull requests. It supports manual coordination; a full web UI is not currently implemented.
