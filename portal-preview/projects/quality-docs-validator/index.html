The problem

The risk lives between documents.

A PFMEA may list an important failure mode while the corresponding Control Plan lacks a control, special-characteristic marking or reaction plan. Checking documents separately can miss these mismatches.

1. Read

Load PFMEA and Control Plan .xlsx spreadsheets using the supported column conventions.

2. Compare

Match process steps and run six explicit, documented checks to identify potential issues.

3. Review

Inspect severity-classified findings, a score and generated Markdown or JSON reports.

Quick start

Run it on your machine.

Clone the repository, then run these commands from its root with Python 3.12+ and the bundled synthetic XLSX examples:

pip install -e .
qdv pfmea-control-plan \
  --pfmea examples/pfmea.xlsx \
  --control-plan examples/control-plan.xlsx \
  --out report.md

What it does not claim

Findings are potential inconsistencies requiring human judgement. This tool does not replace engineering review, verify conformance with IATF/ISO requirements, or provide certification.
